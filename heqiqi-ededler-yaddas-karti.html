Riyaziyyat • 8-ci sinif

HƏQİQİ ƏDƏDLƏR

Yadda saxla: həqiqi ədədlər ədəd oxunda təsvir edilə bilən bütün ədədlərdir.

1. Ədədlər çoxluğu

  • N – natural ədədlər: 1, 2, 3, ...
  • Z – tam ədədlər: ..., −2, −1, 0, 1, 2, ...
  • Q – rasional ədədlər: a/b, b ≠ 0
  • I – irrasional ədədlər: kəsr şəklində dəqiq ifadə olunmayan ədədlər
  • R – həqiqi ədədlər: Q ∪ I
N ⊂ Z ⊂ Q ⊂ R

2. Rasional ədəd

İki tam ədədin nisbəti şəklində yazılır:

a/b, b ≠ 0
Nümunə: 3/5, −7/2, 4 = 4/1

Onluq yazılışı sonlu və ya dövri sonsuz ola bilər.

3. İrrasional ədəd

Dəqiq a/b formasında yazıla bilməyən həqiqi ədəddir.

Nümunə: √2, √3, π

Onluq yazılışı sonsuz və dövri olmayan kəsrdir.

4. Ədəd oxu

Hər həqiqi ədədə ədəd oxunda bir nöqtə, hər nöqtəyə isə bir həqiqi ədəd uyğun gəlir.

−2 < −1 < 0 < 1 < 2

5. Modul

Ədədin sıfırdan məsafəsidir.

|a| ≥ 0
|−5| = 5    |3| = 3    |0| = 0

6. Müqayisə qaydası

Müsbət ədədlərdə ədəd oxunda sağda olan daha böyükdür. Mənfi ədədlərdə isə sıfıra yaxın olan daha böyükdür.

−3 < −1 və 2 < 5

🧠 Yaddaş ipucu: “R = Rasional + İrrasional”. Rasionalda nisbət var, irrasionalda isə belə dəqiq kəsr forması yoxdur.

Mini yoxlama: √16 hansı çoxluqlara daxildir? 0,25 rasionaldırmı? −7/3 həqiqi ədəddirmi? Cavab: √16=4 → N, Z, Q, R; 0,25 → Q və R; −7/3 → Q və R.
